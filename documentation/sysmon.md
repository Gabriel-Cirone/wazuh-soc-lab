# Sysmon

## Objective

Sysmon was deployed on the Windows endpoint to improve visibility
into system activity and provide additional telemetry for security
monitoring.

## Configuration

The Wazuh Agent was configured to collect relevant Windows event logs
generated by Sysmon.

## Monitoring Flow

Windows Endpoint
↓
Sysmon
↓
Windows Event Log
↓
Wazuh Agent
↓
Wazuh Manager
↓
Wazuh Dashboard

## Validation

A controlled test was performed to verify that Sysmon-generated events
were collected by the Wazuh Agent and made available for analysis.

## Result

The events were successfully observed through the Wazuh environment.
